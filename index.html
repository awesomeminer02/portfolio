Steel Rail and Trolley Monitor Transport System

Goal

Carry a VESA-mounted monitor along a fixed 13 ft span.

What I did

  • Modeled the rail and adjustable trolley and produced technical drawings in Autodesk Inventor
  • MIG welded the steel structure across more than 100 welds
  • Turned custom trolley wheels on a lathe

Result

Installed and tested the finished system.

React to the Pressure

Goal

Build an engineering-failure carnival game for the Fall 2025 Expo. Ours is a Chernobyl-style control panel: shut off the blinking lights before the reactor melts down.

What I did

  • Laser cut the enclosure and drilled mounting holes for the inputs
  • Designed and 3D printed the valve and switch handles
  • Soldered and repaired wiring, then debugged the Python game code on the Pico

Result

Demonstrated the finished game to the public at Northeastern's Engineering Expo.

Drone Package Delivery System

Goal

Drop a small package from a DJI Mini 2, which has no built-in payload release, without relying on the drone's own controller.

What I did

  • Designed a servo-actuated release mechanism and airframe mount sized to the drone's payload margin
  • Programmed paired Raspberry Pi Pico microcontrollers to trigger the release over shortwave radio

Result

Remotely airdropped a small wheel of cheese into a waiting hand as part of a promposal.

Type
Self-developed project
Date
Spring 2025
Tools
Raspberry Pi Pico (×2), MicroPython, servo actuation, radio link, CAD

Spring-Powered Competition Vehicle

Goal

Build a spring-powered vehicle that travels as far as possible.

What I did

  • Modeled and 3D printed the vehicle with a 1:144 compound gear reduction
  • Tuned printed gear tolerances so the gear train meshed reliably at high reduction

Result

Set the school distance record at 76 m.
